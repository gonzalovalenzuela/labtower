# Pi Console 1.2.1j

## Español
- **iPhone/iPad:** corregida la tarjeta de Net Monitor, que no se abría al tocar una IP (el toque cerraba la tarjeta al instante). Ahora toca la IP subrayada (en la tabla de UPS, listas laterales, WOL, Proxmox u Overview) y aparece; *Ver detalle completo* abre Net Monitor con ese equipo.

**Instalar o actualizar**
```bash
wget https://raw.githubusercontent.com/gonzalovalenzuela/pi-console/deb-builds/pi-console_1.2.1j_all.deb
sha256sum pi-console_1.2.1j_all.deb    # c91c0a1560770b989f0c117f9bccc9e14bea285f652cf95fe51a65199cc0d798
sudo apt-get install -y ./pi-console_1.2.1j_all.deb
```
Recarga la página (en el iPhone: cierra y vuelve a abrir la pestaña o la app web).

## English
- **iPhone/iPad:** fixed the Net Monitor card not opening on tap (the tap closed it instantly). Tap the underlined IP (UPS table, side lists, WOL, Proxmox or Overview) and the card appears; *Full details* opens Net Monitor with that device.

**Install or upgrade**
```bash
wget https://raw.githubusercontent.com/gonzalovalenzuela/pi-console/deb-builds/pi-console_1.2.1j_all.deb
sha256sum pi-console_1.2.1j_all.deb    # c91c0a1560770b989f0c117f9bccc9e14bea285f652cf95fe51a65199cc0d798
sudo apt-get install -y ./pi-console_1.2.1j_all.deb
```
Reload the page (on iPhone: close and reopen the tab or web app).
