# Pi Console 1.2.1b

## Español

- **Duraciones en días desde las 24 h** en todos los paneles: `40h` ahora se ve `1d 16h`.
- Cambia el Resumen (tiempo encendida de la Pi, "hace …") y Net Monitor ("monitoreado"). Proxmox y Admin Panel ya lo hacían.
- Sin otros cambios.

**Instalar o actualizar**
```bash
wget https://github.com/gonzalovalenzuela/pi-console/releases/download/1.2.1b/pi-console_1.2.1b_all.deb
sha256sum pi-console_1.2.1b_all.deb    # 616f53ba12337cb260145bb1dfbb2381bd27049a2f4ab12acb6044fcce485612
sudo apt-get install -y ./pi-console_1.2.1b_all.deb
```
Los datos se conservan. Recarga el navegador con Ctrl+Shift+R.
