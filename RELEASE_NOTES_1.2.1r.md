# Pi Console 1.2.1r

## Español
- **Net Monitor:** icono de basurero en cada equipo para eliminarlo de la lista (solo administradores, con confirmación). Si sigue conectado, el siguiente escaneo lo vuelve a descubrir.

**Instalar o actualizar**
```bash
wget https://raw.githubusercontent.com/gonzalovalenzuela/pi-console/deb-builds/pi-console_1.2.1r_all.deb
sha256sum pi-console_1.2.1r_all.deb    # bb4c70549d79ebc6e2ef2a4a65628e6ca4c171f6e6d5715a7a14400d02c9f70b
sudo apt-get install -y ./pi-console_1.2.1r_all.deb
```

## English
- **Net Monitor:** trash-can icon on every host to remove it from the list (admins only, with confirmation). If it is still connected, the next scan discovers it again.

**Install or upgrade**
```bash
wget https://raw.githubusercontent.com/gonzalovalenzuela/pi-console/deb-builds/pi-console_1.2.1r_all.deb
sha256sum pi-console_1.2.1r_all.deb    # bb4c70549d79ebc6e2ef2a4a65628e6ca4c171f6e6d5715a7a14400d02c9f70b
sudo apt-get install -y ./pi-console_1.2.1r_all.deb
```
