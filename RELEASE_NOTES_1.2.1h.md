# Pi Console 1.2.1h

## Español
- **iPad:** sin botón X en modo kiosko cuando se abre desde el icono de pantalla de inicio (la página ya es pantalla completa y dejó de pedirla al navegador).
- Si ya añadiste el acceso directo, bórralo, créalo de nuevo y abre Overview desde el icono.

**Instalar o actualizar**
```bash
wget https://raw.githubusercontent.com/gonzalovalenzuela/pi-console/deb-builds/pi-console_1.2.1h_all.deb
sha256sum pi-console_1.2.1h_all.deb    # ce1fa818f0d33022fb38e614e864f920b48b16bd0ab4003c44ae85bc2f0e6d01
sudo apt-get install -y ./pi-console_1.2.1h_all.deb
```
Recarga con Ctrl+Shift+R.
