# Pi Console 1.2.1k

## Español
- **UPS Monitor:** las IP de los clientes conectados a cada UPS (sección *Clientes* del detalle) ahora muestran la tarjeta de Net Monitor al pasar el ratón o al tocar (iPhone/iPad), con acceso al detalle completo.

**Instalar o actualizar**
```bash
wget https://raw.githubusercontent.com/gonzalovalenzuela/pi-console/deb-builds/pi-console_1.2.1k_all.deb
sha256sum pi-console_1.2.1k_all.deb    # b697df39f58bbd22e0e634cbcfc7a178ad2a074a1ebabae3bfea1d49b541a6d5
sudo apt-get install -y ./pi-console_1.2.1k_all.deb
```
Recarga la página (en el iPhone, cierra y vuelve a abrir la pestaña).

## English
- **UPS Monitor:** the IPs of clients connected to each UPS (*Clients* section of the detail) now show the Net Monitor card on hover or tap (iPhone/iPad), with a link to the full details.

**Install or upgrade**
