# Pi Console 1.2.1q

## Español
- **iPad/iPhone:** el icono de la app va incrustado en las páginas, así que «Añadir a pantalla de inicio» ya no muestra la letra «P» aunque el certificado HTTPS no sea de confianza.

**Instalar o actualizar**
```bash
wget https://raw.githubusercontent.com/gonzalovalenzuela/pi-console/deb-builds/pi-console_1.2.1q_all.deb
sha256sum pi-console_1.2.1q_all.deb    # 006c506c879895dfc499b078e3b727a87bbad02f6c476b2533a57029065790a2
sudo apt-get install -y ./pi-console_1.2.1q_all.deb
```
