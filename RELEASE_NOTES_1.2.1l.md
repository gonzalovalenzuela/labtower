# Pi Console 1.2.1l

## Español
- **UPS Monitor:** el anillo de batería y de carga ya no se ve cortado en los extremos, y con 0 % no queda un punto suelto.
- Gráficos de voltaje, consumo y temperatura: las etiquetas del valor actual del lado derecho ya no se recortan.

**Instalar o actualizar**
```bash
wget https://raw.githubusercontent.com/gonzalovalenzuela/pi-console/deb-builds/pi-console_1.2.1l_all.deb
sha256sum pi-console_1.2.1l_all.deb    # b490e8fe1a66a4d68e0d9c9186f3f5706b0c0e558c8ece6545dae61f2f6e5faf
sudo apt-get install -y ./pi-console_1.2.1l_all.deb
```
Recarga con Ctrl+Shift+R.

## English
- **UPS Monitor:** the battery and load rings are no longer clipped at the edges, and 0 % no longer leaves a stray dot.
- Voltage, power and temperature charts: the current-value labels on the right are no longer cut off.

**Install or upgrade**
```bash
wget https://raw.githubusercontent.com/gonzalovalenzuela/pi-console/deb-builds/pi-console_1.2.1l_all.deb
sha256sum pi-console_1.2.1l_all.deb    # b490e8fe1a66a4d68e0d9c9186f3f5706b0c0e558c8ece6545dae61f2f6e5faf
sudo apt-get install -y ./pi-console_1.2.1l_all.deb
```
Hard-reload the browser (Ctrl+Shift+R).
