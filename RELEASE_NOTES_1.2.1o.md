# Pi Console 1.2.1o

## Español
- **Nuevo icono de la app** (iPad/iPhone, Android, pestañas): equipos apilados en isométrico, fondo azul marino y LED verde. Quita y vuelve a añadir el acceso directo para verlo.
- Fuentes SVG y script de regeneración en `assets/icons/`.

**Instalar o actualizar**
```bash
wget https://raw.githubusercontent.com/gonzalovalenzuela/pi-console/deb-builds/pi-console_1.2.1o_all.deb
sha256sum pi-console_1.2.1o_all.deb    # 597268a5b13aa2ce4347e4a4738546df33f376d3629092092ec8a69439dccfcb
sudo apt-get install -y ./pi-console_1.2.1o_all.deb
```
Recarga con Ctrl+Shift+R.
