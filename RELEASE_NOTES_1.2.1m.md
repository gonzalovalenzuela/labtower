# Pi Console 1.2.1m

## Español
- **Login: «Recordarme»** con duración a elegir: 1 día, 1 semana, 1 mes o siempre (400 días renovables). Sin marcar, 24 h como antes. En todos los módulos.

**Instalar o actualizar**
```bash
wget https://raw.githubusercontent.com/gonzalovalenzuela/pi-console/deb-builds/pi-console_1.2.1m_all.deb
sha256sum pi-console_1.2.1m_all.deb    # 0781d660ad8da18633cc5de05cada7931e729a6e345c182f87cfd4616f02b5bc
sudo apt-get install -y ./pi-console_1.2.1m_all.deb
```
Recarga con Ctrl+Shift+R.
